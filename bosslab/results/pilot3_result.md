## 3. 変わった決定のうち差の大きい20件の読み

値の差が大きい順に目で読んだ（全163件の内訳は `pilot3_explain_v1.json` / `pilot3_explain_v2.json`）。

- **ポーションの無駄打ち**: `seq304`（INSATIABLE t1、HP51）で v2 は FLEX_POTION を1位にした（v1では4位）。同様に `seq464` で VULNERABLE_POTION、`seq433` で DEXTERITY_POTION が1位。負け確の戦闘で、その場の打点に寄与しないポーションを先に使う形。
- **勝ち筋のある手を落とす**: `seq447`（Queen t2）で v1 は BLUDGEON +0.070（20ロールアウト中6本が勝ち）を選んだが、v2 では -0.770 まで下がり、ほぼ同値の UPPERCUT -0.767 に負けた。immediate を外したことで、勝ちロールアウトの寄与が薄まった。
- **防御寄りになる**: `seq477`（Queen t6、HP1）で v1 は PERFECTED_STRIKE +0.149、v2 は STONE_ARMOR -0.667。`seq474` も v2 は FEEL_NO_PAIN を選ぶ。HP1では妥当にも見えるが、勝ち筋を捨てている。
- 一方で、`seq331`（INSATIABLE t1）は v1 の PERFECTED_STRIKE +0.474 から v2 は COLOSSUS +0.090 へ。進捗項が「将来の被弾を減らす」を評価した形。

読み: v2 は防御とPowerを増やすが、その増え方は「勝ち筋の評価」ではなく「60手ロールアウトの最終HP」に寄っている。ポーションの消費や、勝ちロールアウトを含む手の降格がその副作用として出ている。
