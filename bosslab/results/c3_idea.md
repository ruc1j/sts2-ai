# C3案: エネルギーと強化の上限に、HPを犠牲にせず届く方法

PILOT-4の上限（D1 エネルギー+1 = Queen勝率5.1%、D2 全札強化 = 8.5%、D6 両方 = 13.6%）に、
実機の方針から届く道があるかを、既存のtraceと実装で確認した。ゲームは起動していない。

## 1. エネルギー: 現状の道具では届かない

- エネルギー+1のレリック（BLOOD_SOAKED_ROSE、WHISPERING_EARRING）は、v23+v24の272 runで
  **ショップに一度も並んでいない**（提示0回）。ボスレリック側にしか無い。
- ボスレリックの選択はエージェントに橋渡しされていない。`official_mod/` に RelicBridge は無く、
  `Entry.cs` が差し替える Handler にもレリック選択は無い。つまり今の構成では、選ぶ機会そのものが
  方針の外にある（ゲーム既定のAIが選んでいる）。
- したがってエネルギーを方針で取るには、**RelicBridge の追加（C#）とDLLの再ビルド**が要る。
  追加するなら「ボスレリックの選択肢のうち、最大エネルギーを増やすものを最優先」で、閾値は不要。
  上限はD1のとおり Queen 1.7%→5.1%（3倍）。ただし選択肢の構成はtraceに残っていないため、
  実際に何回提示されるかは、ブリッジを入れて1本走らせるまで分からない。

## 2. 強化: ショップの強化レリックが「提示されているのに買われていない」

- WAR_PAINT（スキル2枚を強化）は 42/272 run で提示・計117回、WHETSTONE（攻撃2枚）は 40 run・113回、
  MOLTEN_EGG（以後の攻撃カードを強化）は 10 run・31回、ショップに並んでいる。
- **購入は0回**。原因は `SHOP_RELIC_SCORES` にこの3つが無く、`_shop_relic_score` が -1 を返すため。
- 現金の制約: ショップの決定2,407件のうち、所持金150以上ののは 461件（19%）。中央値は51。
  買える機会は限られるが、HPを使わない強化としては唯一の現実的な経路。
- 効果の見積もり: D2（全札強化、約10枚）で Queen +8.5pt なので、1枚あたり約0.85pt。
  WAR_PAINT/WHETSTONE の1枚は2枚強化なので、買えたrunでは約+1.7pt。発動見込みは
  「提示かつ所持金が足りる」runで、42+40+10=92run（34%）のうち1〜2割程度と見る（推定）。
- 実装は Python のみ（`SHOP_RELIC_SCORES` に3つを追加）。DLLは不要。

## 3. その他のHPを犠牲にしない経路（今回の範囲では使えない）

- イベントの強化: trace の `text_key` からは強化イベントを特定できず、件数不明。
- APOTHEOSIS/ARMAMENTS: デッキに入ったrunが 1/59・4/59 と稀。
- 経路変更（休憩・ショップを増やす）: PILOT-7のとおり、Act 1で休憩+0.51に対して通常戦+1.01で
  正味 -3.9HP。HPを犠牲にせずには増えない。

## 4. C3としての提案

優先は **2（ショップの強化レリックを買う）**。DLL不要・HP不要で、いま提示を捨てている。
エネルギー（1）は効果の上限が3倍と大きいが、C#のブリッジ追加とDLL再ビルドが前提で、
C2の走行中に並行して入れるものではない。C2の結果を見た後、次にDLLを触ってよい段階で
RelicBridge を検討する、という順序が安全。

## 5. 留保

- 2の効果はD2からの按分で、実際の2枚強化の価値は測っていない。
- 1の上限D1はモデル内の値で、実機のボスレリック提示が +1エネルギーを何回出すかは未測定。
