## 4. 候補（最大3個）

判断の前に、この解析から言える上限を書く。Queenは400HPで、現状のQueen削りは59戦の中央値17%、平均も同程度。生存は中央値7ターン、合算の総火力は約31/ターン。10倍級の踏破率にするには、7ターンで400を削る約57/ターンのQueen火力が要り、現状の3〜4倍。どの候補も単独でこの数字に届く根拠はない。以下は「届く可能性がある領域」を、発動見込みの件数つきで並べたものである。

### 候補A: 報酬方針でStrengthエンジンを優先する

- 内容: 報酬に `RUPTURE` / `CRIMSON_MANTLE` / `INFLAME` が出たときの優先度を上げる。`MAD_SCIENCE` は報酬に出ない（272 trace中0回）ので方針では取れない。
- 発動見込み: `RUPTURE` が報酬に出た run 98/271（採用は39）。`RUPTURE` と `CRIMSON_MANTLE` が同じ run で出たのは 28/271。どちらも出ない run が 138/271 あるので、発動するのは最大4割弱。
- 踏破への筋道: 踏破7本のうち5本が `RUPTURE` を持つ（削り<0.3 の44戦では11本、削り0.3以上15戦では2本）。3節でStrength増加は攻撃1枚あたりのダメージを 13.4→15.4 に上げた。踏破した1戦はAmalgamを5ターン目に倒し、Queenを2ターンで約250削るバースト型。
- 弱い環: 報酬方針を変えても、Strengthが伸びるのは「引けた run」だけ。DEMON_FORMは提示62回中1回しか取られておらず、現行方針はスケーリングをほとんど選んでいない。

### 候補B: Act 3入場HPを底上げする

- 内容: Act 1〜2の休憩・被弾・経路の方針を、HPを残す側に寄せる。
- 発動見込み: Act 3に到達した 83/271 の全 run。
- 踏破への筋道: 踏破7本の入場HPは平均90.1、Queen削り<0.3の44戦は72.9、削り0.3以上の15戦は86.4。1節でQueen削りと生存ターンの ρ=+0.714。HPが1ターン分（約30ダメージ）を買うと、そのまま火力予算になる。
- 弱い環: 入場HPはAct 1〜2の結果であって原因ではない。HPが高い run は他も強い可能性があり、交絡が大きい。効果量の見積もりはこの解析では出せない。

### 候補C: Queen戦の火力をQueenへ寄せる（Amalgamを狙わない）

- 内容: Queen戦でAmalgamへの攻撃をやめ、Queenへ向ける。3節でAmalgam側の削りは最大HP199で頭打ちになり、合算の総火力指標に反映されにくいことを確認した。
- 発動見込み: Queen戦59/271。
- 踏破への筋道: Amalgamへの削りは平均170。これをQueenへ回せばQueen削りは倍以上になる。ただし400には届かず、単独では踏破に至らない。踏破した1戦もAmalgamを先に倒している。
- 判断: 10倍級の根拠がないため、候補としては採らない。候補Aと組み合わせたときの一部品として扱う。

### まとめ

10倍級と見込める候補はAとBの2つで、いずれも単独では根拠が弱い。Aは発動が4割弱に限られ、Bは因果が不明。事前登録の判定（開発用68本で踏破0なら終了、135本で4本以上なら通過）に載せるなら、A+Bを1つの候補として測るのが筋だが、それでも「10倍」を先に確約はできない。実装はまだしていない。
