## 3. str3の異常の分解

対象: `bosslab_act3_str_conf` の 24 trial（12 組、base と str3）。trace から計器を独立に計算し直した。

### 3-1 まず計器の再現
| 指標 | base | str3 |
| --- | --- | --- |
| 総火力/ターン（removed合計÷ターン、trial平均） | 38.80 | 37.18 |
| 消したHP合計（Queen+Amalgam、trial平均） | 266.17 | 240.75 |
| 生存ターン（trial平均） | 6.58 | 6.58 |
| Queenのみ削り（trial平均） | 98.08 | 64.17 |
| Amalgamのみ削り（trial平均） | 168.08 | 176.58 |
| 攻撃の回数（trial平均） | 12.58 | 12.67 |
| 攻撃1回あたりのダメージ（trial平均） | 13.40 | 15.40 |
| INFLAME/DEMON_FORM/RUPTURE使用回数 | 0.33 | 2.08 |
| 最大Strength（中央値） | 1.00 | 5.00 |

比の平均と平均の比は一致しない。removed合計をターン合計で割ると base 40.43 → str3 36.57（差 -3.86）、trialごとの比の平均では 38.80 → 37.18（差 -1.62）。報告の 38.8→37.2 は後者。

### 3-2 分母か分子か
- 生存ターンは base 6.58 → str3 6.58 で差がない。分母は下がっていない。
- 分子（Queen+Amalgamの削り）は base 266.2 → str3 240.8 で減っている。
- 内訳は Queen 98.1→64.2、Amalgam 168.1→176.6。Amalgamは最大HP 199で頭打ちになる。
- Amalgam撃破は base 7/12、str3 8/12。
- 攻撃1回あたりのダメージは 13.40 → 15.40 で、上がっている。最大Strengthの中央値は 1.0 → 5.0。
