## 「Amalgam をより早く倒す」は次 goal 候補として成立つか（1 段落、候補の仮説）

48 組の実測から、Queen 戦闘の意思決定を変えて Amalgam を早く倒す余地は薄い。倒せた組と倒せなかった組で、攻撃カード数（12.67 対 12.67）と開始エネルギー（約 3.2 で同程度）は変わらず、同じ手札から出せる攻撃ダメージもほぼ取り逃がしていない（上 c）。dev5 で H3a/H3c（Queen へ殴り先を変える規則）が Δshave 0 前後で中性〜マイナスだった（`act3_dev5_h3a_analysis.md`）のと同じ方向で、この集合でも「殴り先を変えず火力を引き出す」余地は小さい。差がともなっていたのは Skill（主に Block）カード数（倒せず 10.60 対 倒せ 12.79）と開始強化の有無（倒せ 16/33=48% 対 倒せず 5/15=33%）で、倒せなさは「防御が足りず Amalgam を仕留める前に体力が尽きる」ことと対応する（相関で、因果は主張しない）。Amalgam を早く倒す余地があるとすれば、Queen 戦闘の出し方ではなく、防御を持たせる・火力を足す（強化を持つ）デッキを途中で手に入れる側にある。lab は boss 入場固定でデッキを作れないので、この余地は Act 3 の報酬選択・昇格（フル run）で作る話で、固定入場 1 戦闘の lab では作り出せない。見込みは「Queen 戦闘内の方針変更」としては低い。次の goal にするならフル run パネル（`next_goal_candidates.md` の現 3 相当）で測るべきで、必要な実機時間は大（1 戦闘でなく run 全体を多数 seed で完走）。lab の配対代理では判定材料は出ない。
