# H3a/H3c 確認用の事前登録採否規則（案）

前回の規則（`bosslab/results/act3_hybrid_decision_rule.md`、commit 4693f2e）を引き継ぐ。今回唯一の
学びは「候補が発火しなかった」ことなので、**候補の特別規則が実際に発火していることを測定の前提に格上げする**
条件を 1 条だけ足す。これは案で、先生の承認と leader の確認の後で確定する（このファイル時点では凍結しない）。

## 変更点の要点

confirm4 では H1/H2 の「Amalgam を倒せるなら優先」が self-lockout で一度も発火せず、実測された `Δshave` は
候補 ≒ base（queenfirst）の比較だった（`act3_confirm4_fidelity_causes.md` / `act3_hybrid_record_draft.md`）。
規則 1-6 は「削りが悪化した候補は不採用」と判定するが、発火していない候補は悪化どころか何も変えていない。
なので発火を前提として先に検査し、発火していなければ採否を出さず保留にする。

## 追加する前提条件（新規、G 条）

- G. 発火率の前提（判定の前に検査する）: 候補 arm が入場状態の同じ entry で base と別の第一手を
  選んだ組数を、その集合の配対 12 組から数える（paired behavioral diff、`bosslab_turn_diff.py`/
  `analyze_bosslab.py` の差分で機械的に取れる）。これを `firing_C` と呼ぶ。
  - dev2 と confirm4 の両方で `firing_C ≥ 4`（12 組中 4 組以上で挙動が変わる）を満たさない候補は
    充足候補から外す（発火しない候補は規則 1-6 の判定材料にしない）。
  - 候補が 0 件以上選ばれるが G を満たす候補が無い場合、panel は測定不能で保留（不採用ではない）。
    理由: 候補規則が作動せず base と同一動作で、EVALUATION.md の主指標に対する効果を検定できない。
  - `firing_C` は arm 名（H3a / H3c）ごとに別々に数える。両 arm が G を満たし、かつ削りが良いなら従属則
    （H1 優先）と同様に H3a/H3c 間で規則 2 の向き一致で選ぶ。

## 従来どおり（4693f2e から変更なし、G を通った候補にのみ適用）

規則 1〜6 をそのまま使う（文面は `apply_hybrid_rule.py` に verbatim で固定済みのものを流用）。

1. C\* が confirm4 の主信号 削り割合で `Δshave > 0`、かつ dev2 でも `Δshave > 0`（両集合で同方向）。
2. H3a・H3c の削り割合の向きが dev2 で同じ（ともに `Δshave > 0`）。割れたら機構頑健でなく不採用寄りの保留。
3. confirm4・dev2 両方で `Δfp ≥ 0`（総火力/ターンが base を下回らない）。
4. confirm4・dev2 両方で `Δwin ≥ 0`（勝ちが base を下回らない）。
5. confirm4 の削り割合の配対符号検定で精密二側 p ≤ 0.05。
6. 信頼性の悪化なし（12 組すべて配対、lab 例外・通信障害なし）。新形式 spec だけで組む前提は
   `act3_newfmt_spec_pool.md` を満たすこと。

判定: G を通って 1〜6 をすべて満たす → **採用**。削りが両集合で `Δshave ≤ 0`、または削り悪化かつ火力も
base 下回る、または実装/前提誤りが実測で判明 → **不採用**。削りは改善したが 1〜6 のどれか未满、
または G 不充足（発火せず測定不能） → **保留**。

## 凍結前に決めること（先生/leader 向け）

- G の閾値 `firing_C ≥ 4` の根拠。1/12 だけの挙動差で採否を出すとノイズなので 4/12 以上を要求したが、
  妥当かは確認してほしい。0 件を確実に不採用でなく保留に扱う点が、confirm4 の過ちを繰り返さないための核心。
- 発火の判定を「第一手の差分」でなく arm の特別規則 flag（環境変数や trace の arm 分岐ログ）で直接数える
  形式にするかも選んでほしい。第一手差分なら既存成果物だけで測れるが、規則が作動してもたまたま同じ手を
  選ぶ trial を発火数から外す（保存的だが発火率をやや低く見る）。

## 実測による補正（act3_h3_firing_model.md、dev2・confirm4 base で算出）

既存 base パネルの第一手観測で、H3a/H3c 相当の規則が第一手を変える組数を数えた。H3a は dev2 7/12・
confirm4 5/12 で **4/12 を両集合で上回る**。発火しなかった H1/H2 は第一手差分 0/12 なので、4/12 の閾値は
H3a を通し H1/H2 を保留に回す目的に合う（0 件を不採用でなく保留に扱う設計も 0/12 の実測で意味を持つ）。
一方 H3c は第一手で 0/12。danger 起点の H3c は turn1（HP 高く初回被ダメ 13〜18）では発火せず中盤で発火しうるため、
第一手差分だけを発火率に使うと実際に発火しうる H3c を誤って「発火 0」に落とす。したがって **G 条の発火検査は
第一手だけでなく全ターンの行動差分（arm が作動した意思決定数、`bosslab_turn_diff.py` の配対差分で測れる）に
拡張し、4/12 はその発火イベント数に対する閾値として維持する**。この補正を先生の承認に載せたい。
