## 2. 読み

- **20%に届いたレバーはない。** 最大は D6（エネルギー+1 と全札強化の同時）の 13.6%（8/59）。main の 1.7% に対して8倍で、「10倍級」の手前まで来る。
- **エネルギーと強化は足し算以上に効く。** D1 が 5.1%、D2 が 8.5% で、同時の D6 は 13.6%。Insatiable は 40%→80%→97%。
- **打ち手の上限はほぼ無い。** P1（1ターンの順列をビームで探索）は 1判断 1.83s で 5秒以内に収まるが、勝ち 1/59・削り 0.224 と main 以下。生存だけ 7.1→8.2 に伸びて、削りが減る。ターン計画は「長く生きるが殴らない」方向に寄る。
- **探索の強化も効かない。** P2（1000回）は 1判断 11.4s で 5秒の上限を2.3倍超え、Queen削りは main とほぼ同値（0.130→0.130、0.262→0.273、0.377→0.378、0.267→0.268、n=4）。
- **デッキ単体のレバーは小さい。** D4（基本札を半分）は 3.4%、D5（Strengthエンジン3枚）は 3.4%。Insatiable はそれぞれ 53%・57% で main 40% より上だが、Queen はほぼ動かない。
- 1判断の所要時間は全アームで 0.9〜1.8秒。5秒の制約（CODEWIKI:485）に収まる。

## 3. 実機の方針で届く手段（モデル内の結果からの推定）

- エネルギー: 古代の民のレリック選択（+1エネルギー系を既に最上位）、Act 1〜3ボスのレリック。パネルの実測では 4エネルギーの run は 15/59（25%）あり、踏破7本には 0。上限の D1 が 5.1% なので、単独では届かない。
- 強化: D2 が 8.5%。休憩の SMITH は現状「HP満タン時のみ」で、実測では手落ちが3回しかない。上限側の効果は大きいが、実機で全札強化は無理。
- D6 は「エネルギー+1」と「全強化」の同時で 13.6%。実機で近づけるなら、エネルギー系レリックの優先と、SMITH を増やす経路（HP管理・休息の判断）の両方が要る。
- デッキ削除（D4）とエンジン追加（D5）は単独では小さい。組み合わせ（D6+D4 など）は時間切れで未測定。

## 4. 未実行と留保

- 各アーム1乱数のみ。入場は同じでも乱数で結果が変わる。
- モデル内の値で、実機の勝敗ではない。採否には使わない。
