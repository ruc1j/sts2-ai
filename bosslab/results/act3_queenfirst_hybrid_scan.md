## crossover 結論

- 全6run / 全手番 429 観測で、1ターンで Amalgam に出せる最大 damage の分布: 中央値 21・p75 34・最大 106。Amalgam 入場 effHP は約 199。**1ターン击杀(>=199)は 0 回**。
- よって「今ターンの最大 damage ≥ Amalgam 残HP」を入室直後から満たすことはほぼ無く、Amalgam が手札一撃で落とせるのは**すでに削りきった後（base run で初回击杀可能 turn 平均 5〜6.4）だけ**。=分かれ目は「削り始めてから5〜6手番後」。
- Amalgam 単独撃破 25/72・勝ち 5/72。base は Amalgam を倒すのに 5〜6 手番使う間 Queen(400HP)が削れず、queenfirst は Amalgam を放置して Queen を 30〜70% 削るが Amalgam の自由ダメで殺られる。どちらも勝てない。

## 切替条件 2案（leader 指定の例に沿う）

案1 「今ターンの最大 damage ≥ Amalgam 残HP なら Amalgam、否则 Queen」
- 実装コスト: 小。既存 queen_minion_direct の対象条件を「lethal な時だけ」に絞る。`attack_damage >= minion_hp` の判定は既にある。
- 総火力/ターンへの影響見込み: 中立（対象の張り替えのみ、手番数は不変）。
- リスク/弱点: 入室直後 Amalgam(199)は一撃で落ちないので Amalgam を実質放置=queenfirst 相当。上表の queenfirst 勝ち 1/12×3 集≈5/72 が現実的な期待値。分かれ目データ上ほぼ Queen 固定に収束。

案2 「2ターン先までに Amalgam を倒せるなら Amalgam、否则 Queen（先読み）」
- 実装コスト: 中。2手番分の damage 予測（rollout の順行シミュレーションを再利用、または p75×2≈68 未満で Amalgam 削り込みとみなす簡易式）。
- 総火力/ターンへの影響見込み: base 側にやや傾く。Amalgam がすでに ~68 以下（≒2ターンで落とせる）になってから投入する設計なので、投入時点の手番数は案1より減る見込み。
- リスク/弱点: 2ターン計画が Amalgam の block 取得や Queen の buff/heal で裏返ると、投入した 2 手番が無駄。しかも Amalgam が「68 以下」になる自体が base の削り込み前提で、対象切替だけでは到達しにくい（循環）。

## 推奨（上記2案の評価結果から）

純粋な「击杀可能か」条件では Amalgam 199HP が 5〜10 手番の投資を要するため、切替だけで Act3 勝率は上がらない見込み（confirm 判定保留＝Queen削り↑・火力↓・勝↓と整合）。より有望なのは**脅度とバースト基準**の切替: (a) Amalgam の次手番の受ける damage が即死級/防御で捌けないとき、または (b) RUPTURE+VULN+Strength 等で Amalgam を数手番で仕留める火力ラインが揃ったときだけ Amalgam、否则 Queen 削り。案1・案2 はこれで代替评估するため、leader のラボ実験ではこの閾値型を arm として足す価値がある。詳細な各 trial 表は上の run 別表にある。
