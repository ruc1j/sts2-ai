# PILOT-7: 強化とエネルギーに、HPを犠牲にせず届く手段はあるか

ゲーム起動なし、凍結物（C1, `~/.sts2/wt-clear5c`）には触れていない。CPUは2コアまで。
対象は `astra_ctrl_v23`+`v24` の272 run（うちQueen入場59）。

## 1. 入手経路の棚卸し

休憩（272 run の decision 数）: SMITH 777、HEAL 928、HATCH 26。SMITHは250/272 run に1回以上あり、1 run あたり 2.86回。
Queen入場時の強化済み札は中央値10枚（平均10.0）。

強化の経路（Queen入場59 run で数えた所持数）:
- SMITH: 上記 777回（ただしAct 1〜3の合計で、Queen入場までに限るとその大半）
- 強化系レリック: WAR_PAINT 13 run、WHETSTONE 5、MOLTEN_EGG 2（合計20/59 run がどれか所持）
- 強化するカード: ARMAMENTS 4 run、APOTHEOSIS 1 run
- イベントの強化オプション: trace の `text_key` からは0件（イベントの選択肢は記録されているが、強化を表す文字列が無い）

エネルギー（Queen入場59 run）:
- 最大エネルギー4の run は15/59。内訳は BLOOD_SOAKED_ROSE 4、WHISPERING_EARRING 7（重複なし）、残り4本は特定できず。
- **レリックの提示そのものが trace に残らない**（`phase` に relic 選択が無い。Neowの選択肢だけは `event` 行に残る）。したがって「選べたのに選ばなかった件数」は v23+v24 の記録からは数えられない。Neowの提示は記録があり、エネルギー系レリックはNeowの選択肢には出ていない（BLOOD_SOAKED_ROSE/WHISPERING_EARRINGはボス報酬側）。

## 2. 経路を「休憩・ショップ最大化」に変えた場合

v23 の Act 1 マップダンプ136件で、全経路を列挙して比べた。

| 経路 | Monster | RestSite | Shop | Elite |
| --- | ---: | ---: | ---: | ---: |
| 現行（戦闘最小優先） | 3.95 | 3.28 | 1.18 | 1.33 |
| 休憩最大化 | 4.96 | 3.79 | 1.23 | 1.14 |
| 差 | +1.01 | +0.51 | +0.05 | -0.19 |

- 休憩が1つ以上増えるマップは 59/136（43%）。平均では Act 1 あたり +0.51。
- 代わりに通常戦が +1.01。CODEWIKI:150 の実測（Monster -17 HP、Rest +26 HP）で換算すると **正味 -3.9 HP**。休憩を増やす経路は、HPを犠牲にせずには取れない。
- ショップはほぼ増えない（+0.05）。

## 3. SMITHの強化先の見直し（部分アーム）

D2（全札強化）で効いたので、少ない強化回数で効く選び方を比べた。Queen入場20件・1乱数・N=3枚のみ強化。

| 選び方 | Queen削り平均 | 勝ち | 生存 |
| --- | ---: | ---: | ---: |
| ベース（強化なし） | 0.214 | 0/20 | 6.8 |
| 現行の SmithCardSelector 順 | 0.208 | 0/20 | 7.0 |
| ダメージ増加の大きい札から | **0.236** | 0/20 | — |

20件では差はノイズの範囲（±0.02〜0.05）だが、向きは「攻撃の強化を先に」が良い。N=6 はCPU 2コアの制約で未実行。

## 4. 候補（最大2つ、実装はまだしない）

10倍級（Queen勝率20%）に届く見込みの候補は、今回の棚卸しからは作れない。材料として残せるのは次の2つ。

- 候補P: **SMITHの強化先を「ダメージ増加の大きい攻撃」優先に変える**。発動見込みは SMITH がある run 250/272（92%）で、1 run あたり 2.86回。踏破への筋道は、強化1枚あたりの打点増がQueen削りに効くこと（D2で+0.17pt/枚相当の上限、N=3の部分アームで +0.02）。10倍には遠い。
- 候補Q: **エネルギー系レリックの優先**。発動見込みは4エネルギーを持つ run 15/59（Queen入場）だが、提示が記録に残らないため、選択の改善余地は測れていない。D1（+1エネルギー）のモデル内効果はQueen勝率1.7%→5.1%で、3倍。これも10倍には届かない。

## 5. 留保

- レリック提示が trace に無いため、「選べたのに選ばなかった」件数はエネルギー側だけ数えられない。
- Step 2 は Act 1 マップ136件のみ（Act 2/3 のダンプは未整備）。
- Step 3 は n=20 の1乱数。勝ちは0で、削りの差だけを見ている。
