# 探索の共通乱数ととどめ判定の比較計画 v5

実行条件の原本は`data/astra_eval_v5_plan.json`。`docs/EVALUATION.md`に従う。結果を見た後にseed・反復数・版を変更しない。

## 比較するもの

- 仮説: 探索で各候補手のk回目の先読みを同じ乱数列で始める（共通乱数）ことと、生きている主敵が1体ならその敵を倒しきる局面を「とどめ」の判定に含めることで、戦闘中の選択の誤りが減り、踏破率または到達度が改善する。
- 変更の種類: 戦闘中の判断に関わる2件の組合せ（探索の変更と判断の変更）。ゲーム再現の正しさとは別。14:00までに別々のパネルを回せないため、実走前に組合せにした。
- 対照`a2475a2`（v4の候補）、候補`82e64a4`（ブランチ`eval-v5-candidate`、v4候補に`25f275e`と`7d2dacb`を適用）。差分は`combat.search`の乱数の作り方と、`official_agent.py`の`finishing_target()`のみ。
- 局所検証: v1・v2の`rollout_success`局面150個で、共通乱数2000回（別seed）の最善手を正解とすると、探索100回の選択の一致率は旧方式84%・共通乱数92%、正解との評価値の差の平均は0.0072・0.0019（`data/crn_eval.py`）。とどめ判定はD0E3 v3候補seq254（HP8・OVICOPTER残り17、攻撃する卵3体）でBash→StrikeでOVICOPTERを倒す判断に変わる。
