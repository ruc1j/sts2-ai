# 報酬の見送り規則とショップのレリック購入の比較計画 v4

実行条件の原本は`data/astra_eval_v4_plan.json`。`docs/EVALUATION.md`に従う。結果を見た後にseed・反復数・版を変更しない。

## 比較するもの

- 仮説: デッキ16枚以上・強ブロック3枚未満のときにS/Aランクの報酬まで見送る規則を外し、余ったゴールドで点数表にないショップのレリックを買うと、デッキと装備が育ち、踏破率または到達度が改善する。
- 変更の種類: 取得方針の変更2件の組合せ。14:00までに別々のパネルを回せないため、実走前に組合せにした。
- 対照`680bfb4`（v3の候補）、候補`a2475a2`（ブランチ`eval-v4-candidate`、v3候補に`bb63f42`と`7290703`を適用）。差分は`choose_card_reward`の見送り分岐の削除、`choose_shop`の余剰ゴールドでのレリック購入（購入後150残る場合のみ）、回帰テスト。
- ショップの変更: D6 v2候補seq343は598ゴールドでPantographを見送った。全traceで該当するショップ訪問は7回。
- 局所検証: v2の24 runで見送り92回のうち50回がこの規則によるもの（44回はS/Aランク）。全traceの報酬3346件（重複除去）を旧版・新版で判定すると、変わるのは158件で、すべて見送り→取得。逆方向は0件。確認用7FCFはAct 1から最終ボスまでデッキ16〜19枚で報酬20回中12回を見送った。Insatiable戦の開始時デッキは勝利戦闘平均27.3枚・敗北21.0枚（相関）。

悪化3件はいずれも報酬の取り方から分かれた（7FCFはTremble、B625はUnmovable、B7BCはDark Embrace）。余剰ゴールドのレリック購入は候補の全runで1回（D0E3がGorget）しか発動していない。

対応: `bb63f42`（報酬の見送り規則の撤廃）を`1964271`で取り消した。ショップの変更（`7290703`）は発動1回で効果を判別できないため保留としてmainに残す。v5はこの比較の候補（報酬規則を外した版）を対照に積んでいるので、v5の結果は共通乱数ととどめ判定の差として読み、報酬規則の有無とは切り離す。
